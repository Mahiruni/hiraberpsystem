# HisabERP Marketing Site

Premium, mobile-first SaaS/fintech redesign for HisabERP.

## Stack
- Next.js 15
- React 19
- Tailwind CSS
- Framer Motion
- Lucide icons
- Pure canvas particle field

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

The site is optimized for Vercel and uses no remote image or font dependency.
